# Site – Dr. Lucas Mendes · Quiropraxia

Site estático (HTML, CSS e JS puros), sem build. Abra `index.html` no navegador.

## Personalizar
- **Nome, textos, endereço, telefone e e-mail:** `index.html`
- **WhatsApp do formulário:** constante `WHATSAPP` em `script.js` (DDI + DDD + número)
- **Cores:** variáveis no topo de `styles.css`

## Fotos reais (opcional)
Coloque estes arquivos em `img/` e eles aparecem sobre as ilustrações automaticamente:
- `hero.jpg`: foto principal (ideal: retrato vertical, ~1200×1400)
- `clinica.jpg`: foto da clínica ou do profissional na seção "Sobre" (~1000×1150)
Se o arquivo não existir, a ilustração em SVG continua sendo exibida.
