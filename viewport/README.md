# Viewport · site de apresentação

Site do estúdio Viewport, de Nicolas Freds. HTML, CSS e JS puros, sem build. Abra `index.html` no navegador.

## Personalizar
- **WhatsApp do formulário:** constante `WHATSAPP` no topo de `script.js` (DDI + DDD + número, só dígitos). Vazio, o botão abre o WhatsApp com a mensagem pronta para escolher o contato.
- **Textos, serviços, dúvidas e região de atendimento:** `index.html`
- **Links "Ver site ao vivo":** em cada `<article class="case">` do `index.html`
- **Cores e fontes:** variáveis no topo de `styles.css` (tema claro e escuro)

## Imagens
As capturas em `img/` são dos projetos do portfólio (Quiropraxia Dr. Lucas Mendes, CozyPaws e Hously), em versão computador (1440 × 900) e celular (390 × 844).
